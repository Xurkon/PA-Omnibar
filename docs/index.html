Features

🌍 Ascension Ready

Fully compatible with Project Ascension's custom spells. Intelligent name-based fallback ensures tracking works even with custom IDs.

⚔️ PvP Dominance

Track enemy interrupts, defensives, and offensive cooldowns in real-time. Automatically adjust visibility for Arena and BGs.

🎨 Visuals

Glow animations on use, skin support via Masque, and transparency controls for a clean, modern UI integration.

🛠️ ElvUI Support

Patched specifically to work seamlessly with ElvUI Enhanced on 3.3.5a, preventing common conflicts and errors.

Slash Commands

/ob Open the configuration menu
/omnibar Alternative command to open configuration

v1.5.0 - Combat Log Spec Detection & Bug Fixes

🌟 New Features

  • Combat Log Spec Detection: Implemented advanced spec detection for arena/PvP using combat log event sniffing (adapted from Gladdy addon).
    • Added 130+ spell/buff-to-spec mappings for all classes.
    • Detects enemy specs from signature spell casts and buff applications.
    • Enables accurate spec-specific cooldown adjustments in arena without inspection.
    • Validates detected specs against player class to prevent false positives.

🛠️ Bug Fixes

  • Guild Chat Error: Fixed "Unknown addon chat type" error when not in a guild on certain realms.
    • Added validation to prevent sending addon messages to GUILD channel when not guild member.

📝 Technical Details

  • New SPEC_SPELLS table: Maps offensive spells to specs (e.g., Penance → Discipline).
  • New SPEC_BUFFS table: Maps buffs/debuffs to specs (e.g., Shadowform → Shadow).
  • New TrySetSpec() function: Validates detected specs using GetPlayerInfoByGUID().
  • Enhanced COMBAT_LOG_EVENT_UNFILTERED handler for spec detection on 3.3.5a clients.

v1.4.0 - Sync and Maintenance

  • File Sync: Updated repository with missing local development files.
  • Version Bump: Incremented version to 1.4.0.

v1.3.0 - Ascension Compatibility From TurboDebuffs

  • Initialization Overhaul: Removed duplicate functions causing startup errors.
  • Chat Channel Guard: Fixed errors when sending version checks.
  • ElvUI Enhanced Compatibility: Patched AddonsCompatibility.lua conflicts.
  • Ascension Spell Support: Name-based fallback for custom spells.
  • Shimmed APIs: Added shims for C_PvP, C_Timer, etc.
